# AI 产品规划

## 何时使用
- 你有一个模糊的产品想法，不知道该做什么功能、为谁做、为什么做。
- 你盯着空白文档无从下手，需要 AI 当"产品合伙人"做头脑风暴。
- 你要明确 MVP 的核心功能边界，区分"当前做"和"未来做"。
- 你要把想法转成可执行的产品蓝图/PRD。

## 核心规则

1. **把 AI 当"产品合伙人"而非搜索引擎**：面对空白文档，让 AI 帮你头脑风暴、梳理思绪、挑战假设，把模糊想法变成清晰的产品蓝图（回答"为什么做/为谁做/做什么"）。来源：第5章

2. **用"超级提示词"而非随口问**：随口问"习惯追踪器需要什么功能"会得到宽泛无用结果。结构化提示词应包含三要素：**角色**（扮演经验丰富的产品经理）+ **任务**（为 X 产品头脑风暴生成功能列表）+ **格式要求**（分"核心功能/MVP必备"与"创新/高级功能"两类，每条一句话描述作用）。来源：第5章

3. **从 AI 报告里剥离三层价值**：①市场与用户心理分析（竞品逻辑+心理学理论，如 Fogg 行为模型"行为=动机+能力+提示"、上瘾模型）；②功能规划（核心 vs 创新，明确 MVP 边界）；③战略建议（分阶段路线图）。别只当清单看。来源：第5章

4. **MVP 只做"核心循环"**：核心功能构成 MVP 基石，满足基本期待，首要任务是把它们打磨得简单易用，而非急于加高级特性。分阶段：①发 MVP 验证核心循环 → ②加深参与 → ③用智能功能做差异化壁垒。来源：第5章

5. **"不做什么"和"做什么"同样重要**：审视高级功能实际是在为产品选"灵魂"（极简数据追踪者/高游戏化激励器/引导式健康教练），并权衡便利性 vs 隐私合规（自动化追踪便利但对数据权限要求更高；手动记录更可控但操作成本高）。来源：第5章

6. **健康/信任类产品从第一天就落实数据安全**：对用户透明、遵守法规，把信任当最宝贵资产，而非事后补救。来源：第5章

## 检查清单
- [ ] 是否用"角色+任务+格式要求"的超级提示词启动头脑风暴，而非随口问？
- [ ] 是否从 AI 报告中提炼了市场分析、功能分层、分阶段战略三层价值？
- [ ] MVP 是否只覆盖核心循环（如"创建习惯→追踪进度→获得反馈"），没塞高级功能？
- [ ] 是否明确了产品的价值主张/哲学（选"灵魂"），并做了取舍（做什么 vs 不做什么）？
- [ ] 涉及敏感数据（健康等）时是否把安全合规排进了第一天计划？
